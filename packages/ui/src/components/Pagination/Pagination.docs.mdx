# Pagination

Componente de navegação entre páginas baseado no `Pagination` do Material UI. Use-o quando a pessoa usuária precisar percorrer resultados divididos em páginas, como listagens de projetos, pesquisas e relatórios.

### Acessibilidade

- Mantenha a paginação em uma área identificável da página quando houver mais de um conjunto de controles.
- Use `aria-label` para descrever o conjunto quando o contexto visual não for suficiente.
- A página atual é anunciada pelo componente do MUI com `aria-current`.
- Garanta que a ordem de foco siga o fluxo da página e que os itens possam ser acionados pelo teclado.
