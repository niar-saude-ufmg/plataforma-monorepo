### Exemplo de aplicação
```tsx
import { Checkbox } from "@niar/ui";
export function Terms() {
  return <Checkbox label="Aceito os termos de uso" />;
}
```
### Acessibilidade
- Sempre associe um rótulo visível ou `aria-label` ao controle.
- Use `disabled` quando a opção não puder ser alterada.
