# FileUpload

Área para selecionar ou arrastar arquivos, exibindo os arquivos escolhidos e permitindo removê-los.

### Exemplo de aplicação
```tsx
import { FileUpload } from "@niar/ui";
export function Documents() {
  return (
    <FileUpload
      accept=".pdf"
      description="Envie o documento em formato PDF"
      onChange={(files) => console.log(files)}
    />
  );
}
```
### Acessibilidade
- Mantenha um rótulo acessível para o input.
- Indique os formatos aceitos no texto da interface.
- Ofereça remoção individual para cada arquivo selecionado.
