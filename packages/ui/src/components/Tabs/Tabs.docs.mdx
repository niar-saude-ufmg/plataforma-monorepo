### Exemplo de aplicação
<Source
  dark
  language="tsx"
  code={`import { Tabs } from "@niar/ui";

export function ProjectTabs() {
    return (
      <Tabs
        defaultValue="overview"
        options={[
          { value: "overview", label: "Visão geral" },
          { value: "documents", label: "Documentos" },
        ]}
      />
    );
}`}

### Acessibilidade - Use rótulos claros e únicos para cada aba. - Mantenha
`aria-label` quando houver mais de uma navegação.
