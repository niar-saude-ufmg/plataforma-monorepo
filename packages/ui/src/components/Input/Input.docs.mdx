### Exemplo de aplicação

```tsx
import { Input } from "@niar/ui";
export function Credentials() {
  return (
    <Input label="Senha" type="password" autoComplete="current-password" />
  );
}
```

### Acessibilidade

- Mantenha um `label` visível e associado ao campo.
- Use `type="email"` e `autoComplete` apropriados para o contexto.
- O botão de visibilidade da senha possui nome acessível e pode ser acionado pelo teclado.
