# StatusChip

Indicador visual para estados de projetos e etapas do fluxo. Use `display="chip"` para a apresentação com fundo suave e `display="text"` em tabelas compactas.

### Acessibilidade

- O label deve comunicar o estado sem depender apenas da cor.
- Use textos curtos e consistentes para facilitar a leitura em tabelas.
