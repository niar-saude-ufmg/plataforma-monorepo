### Exemplo de aplicação
```tsx
import { Button, Dialog } from "@niar/ui";
export function Confirmation() {
  return (
    <Dialog
      open
      title="Confirmar envio"
      onClose={() => undefined}
      actions={<Button variant="contained">Confirmar</Button>}
    >
      Deseja enviar este projeto?
    </Dialog>
  );
}
```
### Acessibilidade
- Mantenha um título ou nome acessível para identificar o dialog.
- Permita fechar pelo botão de fechar e pela ação de escape.
- Use ações com rótulos claros para confirmar ou cancelar.
