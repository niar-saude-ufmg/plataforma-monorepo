# Dialog

Painel modal para confirmar ações ou exibir informações que exigem atenção.

Para dialogs de confirmação que devem ser fechados somente por uma ação explícita,
use `closeOnBackdropClick={false}` e `disableEscapeKeyDown`, normalmente com
`showCloseButton={false}` e um botão Cancelar nas `actions`.

### Exemplo de aplicação
<Source
  dark
  language="tsx"
  code={`import { Button, Dialog } from "@niar/ui";
export function Confirmation() {
    return (
      <Dialog
        open
        title="Confirmar envio"
        showCloseButton={false}
        closeOnBackdropClick={false}
        disableEscapeKeyDown
        actions={
          <>
            <Button>Cancelar</Button>
            <Button variant="contained">Confirmar</Button>
          </>
        }
      >
        Deseja enviar este projeto?
      </Dialog>
    );
}`}
/>
### Acessibilidade - Mantenha um título ou nome acessível para identificar o
dialog. - Permita fechar pelo botão de fechar e pela ação de escape. - Use ações
com rótulos claros para confirmar ou cancelar.
