### Exemplo de aplicação
```tsx
import { Timeline } from "@niar/ui";
export function History() { return <Timeline items={[{ title: "Projeto submetido", date: "Hoje, 10:30" }]} />; }
```
### Acessibilidade
- Mantenha os eventos em ordem cronológica.
- Use títulos e datas compreensíveis.
