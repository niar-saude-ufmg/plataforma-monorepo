# Menu

### Props
<Controls of={Stories.Playground} sort="alpha" />
### Exemplo de aplicação
<Source
  dark
  language="tsx"
  code={`import { Menu } from "@niar/ui";
export function MainMenu() {
    return (
      <Menu
        groups={[{
          label: "Arquivo",
          items: [
            { label: "Novo projeto", onClick: () => console.log("novo") },
            { label: "Abrir", href: "/projetos" },
          ],
        }]}
      />
    );
}`}
/>
### Acessibilidade - Use rótulos claros para grupos e itens. - Itens
desabilitados devem permanecer compreensíveis.
