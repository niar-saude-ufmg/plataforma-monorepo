# Table

Tabela para listagens da plataforma. As colunas aceitam `render` para compor StatusChip, ações, seleção e outros conteúdos React. A paginação usa o `TablePagination` do MUI e o Collapsible pode renderizar uma tabela de detalhes.

### Exemplo de aplicação

<Source
  dark
  language="tsx"
  code={`import { Table } from "@niar/ui";

const columns = [
  { key: "name", label: "Projeto" },
  { key: "status", label: "Status" },
];

const rows = [{ name: "Projeto A", status: "Em análise" }];

export function ProjectTable() {
    return <Table columns={columns} rows={rows} />;
}`}
/>

### Acessibilidade

- Use `aria-label` quando o contexto não identificar a tabela.
- Mantenha labels descritivos nas colunas.
- Em ações e seleção, forneça um nome acessível para cada controle.
