# DatePicker

Campo de data baseado no input nativo do navegador, com o label retraído e a identidade visual do Design System. A pessoa usuária pode clicar em qualquer área do campo para abrir o seletor de data.

### Exemplo de aplicação

<Source

export function CoepOpinion() {
  return (
    <DatePicker

      value={approvalDate}

  );

### Acessibilidade e interação

- Mantenha um `label` visível e associado ao campo.
- Use valores no formato `YYYY-MM-DD`, conforme o input nativo de data.
- O campo recebe `cursor: pointer` e abre o seletor ao clicar na área do campo.
- Use `required`, `error` e `helperText` para comunicar as regras de validação.
