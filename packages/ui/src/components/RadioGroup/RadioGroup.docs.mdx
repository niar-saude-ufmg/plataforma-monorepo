### Exemplo de aplicação

<Source
  dark
  language="tsx"
  code={`import { RadioGroup } from "@niar/ui";
export function DataOrigin() {
    return (
      <RadioGroup
        label="Origem"
        options={[
          { value: "own", label: "Base própria" },
          { value: "niar", label: "Base do NIAR" },
        ]}
      />
    );
}`}
/>

### Acessibilidade

- Use um `label` que descreva o grupo.
- Mantenha rótulos distintos para cada opção.
