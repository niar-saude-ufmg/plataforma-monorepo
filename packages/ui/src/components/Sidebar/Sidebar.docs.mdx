### Exemplo de aplicação
<Source
  dark
  language="tsx"
  code={`import { Sidebar } from "@niar/ui";

export function Navigation() {
    return (
      <Sidebar

### Acessibilidade - Mantenha um nome acessível para a navegação. - Use
`selected` para comunicar a página atual. - Forneça rótulos para todos os itens,
mesmo quando houver ícones.
