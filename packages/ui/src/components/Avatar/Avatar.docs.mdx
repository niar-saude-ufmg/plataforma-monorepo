### Exemplo de aplicação

```tsx
import { Avatar } from "@niar/ui";

export function UserAvatar() {
  return <Avatar alt="Usuário NIAR">UN</Avatar>;
}
```

### Acessibilidade

- Forneça `alt` quando o avatar usar uma imagem.
- Use um texto alternativo que identifique a pessoa, evitando informações redundantes.
- Quando o avatar for interativo, envolva-o em um controle com nome acessível.
