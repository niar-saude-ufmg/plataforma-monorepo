# Chat

Conversa reutilizável do assistente. A apresentação fixa integra o layout; a flutuante permite minimizar, maximizar e restaurar sem perder o histórico ou o texto digitado.

Estrutura de uma mensagem, compatível com a API do assistente:

<Source dark language="tsx" code={`type ChatMessage = {
  id: number | string;

  created_at?: string;

O evento `onSend` recebe o texto e deve retornar a mensagem de resposta completa. A conversão para o protocolo interno é feita pelo componente. `onMessagesChange` informa o histórico visual, que pode conter IDs temporários antes da persistência.

As mensagens são exibidas sem avatar. Os nomes dos participantes podem ser personalizados em `roleDisplayNames`, sem alterar os valores de `role`.

Os eventos `onMinimize`, `onMaximize` e `onRestore` notificam ações da janela, sem exigir que a aplicação controle seu estado. Restaurar uma janela minimizada retorna ao tamanho que ela tinha anteriormente.

### Exemplo de aplicação

<Source dark language="tsx" code={`import { Chat } from "@niar/ui";

<Chat
  key={session.id + ":" + activeSection}
  variant="fixed"
  title="Assistente do projeto"
  subtitle="Seção: Contexto"
  messages={sectionMessages}
  onSend={(content) => api.projectChat(session.id, content)}
  onError={(error) => reportError(error)}
/>`} />

A aplicação seleciona as mensagens por conversa e seção antes de passá-las ao componente. Ao trocar de conversa, use uma `key` diferente para reiniciar o histórico local e o rascunho. O componente não seleciona endpoints nem persiste mensagens por conta própria.

### Falhas de envio

Quando `onSend` rejeita a Promise, o chat exibe uma mensagem de falha e a ação **Tentar novamente**. O texto enviado retorna ao campo caso o usuário ainda não tenha iniciado outro rascunho. `onError` permite registrar a falha na aplicação. No Playground, envie **erro** para testar esse estado.

### Acessibilidade

A região utiliza o título como nome acessível, ou `aria-label` quando informado. Os controles têm nomes traduzíveis em `localeText`. Minimizar transfere o foco para restaurar; reabrir transfere o foco para o campo de mensagem. `disabled` impede compor e enviar mensagens.
