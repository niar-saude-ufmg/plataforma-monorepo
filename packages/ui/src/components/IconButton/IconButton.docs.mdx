# IconButton

Botão compacto que usa um ícone para representar uma ação.

<Canvas of={Stories.Playground} />

<Canvas of={Stories.Actions} />

### Exemplo de aplicação

```tsx
import { IconButton } from "@niar/ui";
export function CloseAction() {
  return <IconButton name="close" aria-label="Fechar" />;
}
```

### Acessibilidade

- Sempre forneça `aria-label` descrevendo a ação.
- Não use apenas o nome visual do ícone como alternativa acessível.
