# Autocomplete

Campo de busca e seleção baseado no Autocomplete do MUI. É indicado para filtros e seleção de entidades quando a lista de opções pode crescer.

Quando `freeSolo` está habilitado, a pessoa usuária pode digitar valores que não estão na lista. Nesse modo, o MUI pode ocultar a seta do menu automaticamente. Use `forcePopupIcon={true}` somente quando for necessário manter o menu de opções visível nesse cenário.

### Acessibilidade

- Use um label descritivo para identificar o campo.
- Garanta que a seleção possa ser feita pelo teclado.
- Use `disabled` quando o campo não estiver disponível para interação.
