# Switch

O `Switch` representa uma configuração binária e segue a API de eventos do MUI.

### Props

- `label`: texto associado ao controle.
- `checked`: valor controlado pelo componente pai.
- `disabled`: impede a interação.
- `slotProps`: props nativas das partes internas do MUI, incluindo atributos de acessibilidade do input.

### Exemplo de aplicação

<Source dark language="tsx" code={'import { Switch } from "@niar/ui";\n\n<Switch\n  label="Ativar notificações"\n  checked={notificationsEnabled}\n  onChange={(_, checked) => setNotificationsEnabled(checked)}\n/>'} />

### Acessibilidade

Use `label` ou forneça um nome acessível em `inputProps`. O estado deve ser comunicado pelo valor controlado de `checked`.
