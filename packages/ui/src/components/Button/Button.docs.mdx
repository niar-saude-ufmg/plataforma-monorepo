### Ícones

O `Button` herda as propriedades `startIcon` e `endIcon` do MUI para exibir um ícone antes ou depois do texto. Quando o botão tiver somente um ícone, informe um `aria-label` descritivo.

### Acessibilidade

- Use um rótulo que descreva a ação e mantenha o texto visível.
- Preserve o foco visível ao navegar pelo teclado.
- Use `disabled` somente quando a ação realmente não puder ser executada.
