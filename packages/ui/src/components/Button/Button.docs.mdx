### Exemplo de aplicação

```tsx
export function ContinueButton() {
  return <Button onClick={() => console.log("continuar")}>Continuar</Button>;
}
```

### Acessibilidade

- Use um rótulo que descreva a ação e mantenha o texto visível.
- Preserve o foco visível ao navegar pelo teclado.
- Use `disabled` somente quando a ação realmente não puder ser executada.
