# Tokens

Os tokens mantêm as decisões visuais do NIAR em uma fonte única e entregam os mesmos nomes para TypeScript e CSS.

## Global e marca

`global.json` contém valores básicos: paleta bruta, escala de espaçamento, tipografia, raios e sombras. Ele é separado fisicamente para organizar a manutenção, mas não adiciona `global` nos nomes públicos. `brand.json` atribui significado a esses valores e gera a API usada no produto, como `niar.colors.action.primary`.

Componentes e páginas devem usar principalmente os tokens definidos em `brand.json`. Isso permite alterar a aplicação da marca sem procurar valores hexadecimais ou medidas espalhados pelo código. Os valores de `global.json` servem para construir e manter esses papéis.

## Uso em componentes

Os componentes de `@niar/ui/components` recebem a configuração padrão pelo `NiarProvider`, usado uma vez na raiz da aplicação React.

```tsx
import { Button } from '@niar/ui/components';
import { NiarProvider } from '@niar/ui/theme';

<NiarProvider>
  <Button color="primary" variant="contained">Continuar</Button>
</NiarProvider>
```

Produtos que precisam ajustar o tema podem criar uma variação e entregá-la ao provider:

```tsx
import { createNiarTheme, NiarProvider } from '@niar/ui/theme';

const theme = createNiarTheme({
  shape: { borderRadius: 12 },
});

<NiarProvider theme={theme}>{/* aplicação */}</NiarProvider>
```

## Uso em páginas

TypeScript usa o objeto `niar`:

```tsx
import { niar } from '@niar/ui/tokens';

<header style={{ color: niar.colors.text.heading, padding: niar.spacing.xl }}>
  Projeto de pesquisa
</header>
```

CSS importa as variáveis uma vez na entrada da aplicação:

```css
@import '@niar/ui/tokens.css';

.project-page {
  color: var(--niar-colors-text-body);
  padding: var(--niar-spacing-xl);
  background: var(--niar-colors-surface-page);
}
```

## Geração

O Style Dictionary 5 lê `global.json` e `brand.json` e resolve os aliases em `tokens/styles/tokens.ts` e `tokens/styles/tokens.css`. O build compila e copia essas duas saídas para `dist`; não existe mais um `generated.ts` solto na raiz dos tokens.
