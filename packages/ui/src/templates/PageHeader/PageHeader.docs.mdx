# PageHeader

Template para estruturar o cabeçalho e a navegação de uma página. A propriedade `navigation` escolhe entre Sidebar lateral, MenuBar horizontal e Tabs.

<Description of={Stories.Playground} />
<Canvas of={Stories.Playground} />

<Controls of={Stories.Playground} sort="alpha" />

### Acessibilidade

- Forneça labels acessíveis nos itens de Sidebar e MenuBar.
- Use `logoAlt` quando o contexto exigir outro texto alternativo.
- Passe as opções de abas pela propriedade `tabs` quando a página tiver abas.
- Use `onChange` para receber o valor selecionado por Sidebar, MenuBar ou Tabs.
