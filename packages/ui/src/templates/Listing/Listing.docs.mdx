# Listing

Template para listagens que combina `Table` com `Skeleton` durante o carregamento e `EmptyState` quando `rows` está vazio.

O cabeçalho é opcional e pode receber `title`, `description` e `action`, como um botão de cadastro. O `filter` também é opcional e recebe um componente React, como o template [Filter](?path=/docs/templates-filter--docs).

`emptyState` aceita `title`, `description`, `icon` e `action` para personalizar o estado vazio. `pagination`, `selectable` e as configurações de sorting são encaminhadas para a `Table`; consulte a [documentação da Table](?path=/docs/componentes-table--docs) para ver todas as propriedades e exemplos.

As props de paginação seguem o `TablePagination` do MUI, incluindo `count`, `page`, `rowsPerPage`, `onPageChange` e `onRowsPerPageChange`.

Para habilitar seleção, use `selectable` e trate as linhas recebidas em `onSelectionChange`. A ordenação é configurada nas colunas da `Table` com `sortable: true`; use `onClick` na coluna para reagir à troca de ordenação.

### Acessibilidade

- Mantenha labels de coluna objetivos e descritivos.
- O título usa `aria-level={1}` por padrão; ajuste esse valor quando o `Listing` estiver inserido em uma hierarquia diferente.
- No estado vazio, o título do `EmptyState` usa `aria-level={3}` por padrão e pode ser personalizado dentro de `emptyState`.
- Defina `aria-label` para identificar a finalidade da lista para tecnologias assistivas.
- Use `loading` enquanto os dados ainda não estiverem disponíveis.
- Use `state="empty"` para comunicar uma busca sem resultados.
