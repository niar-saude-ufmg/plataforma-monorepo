# Footer

Template de rodapé institucional com identidade, navegação, informações e parcerias editáveis.

<Description of={Stories.Playground} />
<Canvas of={Stories.Playground} />

### Props

<Controls of={Stories.Playground} sort="alpha" />

O logo oficial branco é renderizado pelo próprio Footer quando `logo` está habilitado.
`navigation`, `information`, `partners` e `language` recebem conteúdo React para que cada aplicação controle links, textos, imagens e eventos.

- `logo`: habilita o logo oficial e o link para a página definida em `logoHref`.
- `logoAlt`: define o texto alternativo do logo.
- `navigation`: recebe o `nav` e os links exibidos na área de navegação.
- `information`: recebe os dados de contato e localização.
- `partners`: recebe imagens ou qualquer composição React para realização e parcerias.
- `language`: recebe os links ou controles de idioma da aplicação.
- `copyright`: define o texto exibido na faixa inferior.

### Acessibilidade

- Use um `nav` com `aria-label` para identificar o menu do rodapé.
- Mantenha links inverse legíveis sobre o fundo escuro.
